# Data gaps

These are presentation gaps only. This branch does not change the control API.

| Design element                   | Missing field                                                 | Current rendering                                                                            | Suggested later API change                                                                                     |
| -------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Current run drawdown meter       | Current run drawdown in USD                                   | "Not reported" beside the configured drawdown limit                                          | Add `runDrawdownUsd` and its measurement timestamp to the runtime risk snapshot.                               |
| Today PnL                        | A calendar-day window, timezone, and window start             | "Net known result, last 24 hours" from the existing attributed performance window            | Add explicit `windowKind`, `windowStart`, `windowEnd`, and net-known-result fields.                            |
| PnL line                         | Timestamped net-known-result samples                          | The chart is omitted                                                                         | Add a bounded `pnlSeries` with timestamp, realized PnL, known costs, and net result per point.                 |
| Gas runway in days               | Measured gas burn rate and estimated time remaining           | Paid actions after the configured reserve                                                    | Add recent gas spend, sample duration, and conservative runway seconds alongside the existing action estimate. |
| Fill markouts                    | Fair value at 1 s, 10 s, and 60 s after each fill             | Markouts are omitted                                                                         | Add signed 1 s, 10 s, and 60 s markouts to each attributed fill after those windows mature.                    |
| Fill liquidity and fee direction | Maker/taker role plus signed fee components per fill          | Side, notional, realized result, and aggregate known fees only                               | Add `liquidityRole` and signed protocol, venue, rebate, funding, hedge, and gas amounts per fill.              |
| Request access                   | A configured request-access URL or application endpoint       | A mailto link to the operator address                                                        | Expose a public, rate-limited access-request URL or POST endpoint in deployment status.                        |
| Per-venue rollups                | Venue ID on balances, exposure, fills, and performance totals | The configured venue and "All venues" use the same honest totals while only one venue exists | Add `venueId` to account and execution records and return per-venue equity, exposure, PnL, and fee rollups.    |
