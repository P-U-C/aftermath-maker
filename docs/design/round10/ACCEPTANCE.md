The four stall findings: **a. Confirmed:** one unresolved cycle Promise prevented all later ticks; the baseline-main test reproduced it. The Paper cycle token/deadline lets later ticks start. **b. Confirmed:** unbounded maker portfolio and readiness account reads froze cycle/readiness; one shared 15-second venue-read timeout now bounds reads. **c. Confirmed:** Paper did not use the Live quote-age watchdog; Paper now has its own deadline without affecting Live's transaction/watchdog path. **d. Confirmed:** a blocked Paper cycle incorrectly updated `lastSuccessfulCycleAt`; removed and regression-tested. Read freshness is measured from `accountReadAt`, and a stale bundle/log shows the read's time and last error.

The controls replaced: clickable run-state pill → rectangular Kit button; Bundle/Strategy form native selects → one Kit Select; Strategy switches → Kit Toggle; account metadata/collateral and bundle-name inputs → Kit Input; role, revoke, deposit/withdraw and creation controls → Kit Buttons. No inline-styled buttons remain. Existing Paper/Live gates and owner-intent checks are unchanged. The 9 HTTP-unreachable codes have one-line reasons and direct throw tests in `user-facing-routes.test.ts`; Live is never exercised against a real venue.
